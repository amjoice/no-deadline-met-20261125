One single-line joke giving an excuse for a missed deadline, for make.fun's
"One Line, No Deadline Met" bounty ($2 in USDC). The entry is the line and
nothing else: no picture, no link, no second line to set it up.

> I outsourced the deadline to future me, and future me just filed for a transfer.

The line was chosen by sparring 18 candidates head-to-head against the
judge's brief (excuse first, then funny, single-line form, sounds like a real
person cornered, fresh angle). The winner went unbeaten at 5-0 in the
round-robin, then beat four variants of its own angle.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (80 characters, one line, UTF-8).
